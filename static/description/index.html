Facturación Electrónica (e-CF) — GAE

Integración nativa de Odoo 17 con el Gestor de Autorizaciones Electrónicas (GAE) de la DGII para la emisión de Comprobantes Fiscales Electrónicos en República Dominicana.

República Dominicana · Ley 32-23

¿Qué hace este módulo?

🧾

Emisión de e-CF

Envía facturas electrónicas directamente desde Odoo al GAE con un solo clic. Soporta E31 a E47.

🔐

Timbre Digital

Obtiene y almacena el código de seguridad, URL de consulta y fecha de firma devueltos por el GAE tras la aprobación.

📄

QR en el PDF

Agrega automáticamente el QR, código de seguridad y fecha de firma DGII al pie de las representaciones impresas.

🔄

Procesamiento Asíncrono

El GAE procesa en lote. El módulo gestiona los estados: Pendiente → Enviado → Aprobado / Rechazado.

💰

Impuestos Adicionales

Soporte completo para ISC, propina legal (10%) e Impuesto Telecomunicaciones (2%) via array aditionalTaxes.

⚙️

Independiente

Funciona con los módulos oficiales de Odoo (account, l10n_latam_invoice_document) sin dependencias privadas.

Flujo de Uso

1

Configura las credenciales GAE

En Ajustes → Facturación Electrónica (eCF) ingresa tu API Key, URL del GAE y código de punto de venta.

2

Confirma la factura en Odoo

Crea y confirma una factura con tipo de documento electrónico (E31, E32, etc.). El campo Aplica e-CF se activa automáticamente.

3

Envía al GAE

Haz clic en Enviar a DGII (eCF). El payload se construye y envía al endpoint POST /api/Invoice del GAE.

4

Verifica el estado

El GAE procesa en lote. Usa Verificar Estado GAE para consultar si fue Aprobado o Rechazado.

5

Timbre en el PDF

Al aprobarse, el código de seguridad y el QR DGII aparecen automáticamente en la representación impresa.

Requisitos Previos

Antes de instalar este módulo necesitas:
  • RNC activo y vigente ante la DGII
  • Certificado de firma digital vigente
  • Certificación como emisor electrónico ante la DGII
  • Secuencias de e-CF autorizadas cargadas en el GAE
  • Credenciales (API Key) de una cuenta activa en GAE Digital
  • Python: qrcode, requests (se instalan con Odoo.sh automáticamente)
